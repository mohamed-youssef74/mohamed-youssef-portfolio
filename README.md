# Personal Portfolio

My personal portfolio site. Selected work, skills, about and contact in a single animated page.

Live demo: https://mohamed-youssef-portfolio.vercel.app/

## Sections

- Hero with animated title
- Skills ticker
- Selected work with category filters and live demo links (Nour Baqin, Read Zone, Paint Shop Dashboard)
- About
- Contact: email with copy button, GitHub and WhatsApp links

## Tech stack

- Next.js 16, React 19, TypeScript
- Tailwind CSS 4, lucide-react icons
- Deployed on Vercel

## Getting started

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000
